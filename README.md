# Sistema de Restaurante

Projeto desenvolvido em Java como parte dos estudos de programação.

## 🎥 Apresentação do projeto

Confira o vídeo de demonstração e explicação do Sistema de Restaurante:
https://lnkd.in/p/eWzUKrxw

## Sobre o projeto

O sistema permite realizar o gerenciamento de pedidos de um restaurante, desde a escolha e personalização dos lanches até o acompanhamento dos pedidos e o fechamento do dia.

## Funcionalidades

- Cadastro de pedidos
- Escolha de lanches
- Personalização de lanches
- Adição de ingredientes extras
- Consulta e cancelamento de pedidos
- Cálculo do total do dia

## Tecnologias utilizadas

- Java
- Maven
- JUnit
- Git e GitHub

## Como executar

1. Faça o download ou clone este repositório.
2. Abra o projeto no IntelliJ IDEA.
3. Aguarde o Maven carregar as dependências.
4. Execute a classe `Main`, localizada no pacote `app`.

## Testes

Foi criado um teste com JUnit para realizar testes durante o desenvolvimento do projeto.
